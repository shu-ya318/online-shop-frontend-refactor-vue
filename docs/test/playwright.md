# playwright.config.ts

一個區域:e2e 測試。

## e2e 測試

### 設定語法對應效果

| 動作                                | 效果                |
| ----------------------------------- | ------------------- |
| 執行 `npx playwright install`       | 安裝瀏覽器          |
| 跑通 `test:e2e`                     | 驗收標準            |
| e2e 檔案放 `e2e/**`(被 Vitest 排除) | 單元測試與 e2e 分工 |

### 應避免的錯誤

- 把 e2e 檔案納入 Vitest 的執行範圍(`e2e/**` 應被排除)。
