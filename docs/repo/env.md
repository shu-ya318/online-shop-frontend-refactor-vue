# env/.env.example(含 env.d.ts)

一個區域:環境變數集中管理。

## 環境變數

### 設定語法對應效果

| 設定                                        | 效果                 |
| ------------------------------------------- | -------------------- |
| 環境變數集中在 `env/`,Vite 以 `envDir` 讀取 | 檔案位置統一         |
| 提供 `env/.env.example`                     | 範本納入版本控制     |
| 只有 `VITE_` 開頭的值暴露給前端             | 前端只拿得到公開設定 |
| 缺少環境變數時有明確提示                    | 驗收標準             |

### 應避免的錯誤

- 機密資訊放在前端環境變數(`VITE_` 開頭的值會暴露給前端)。
