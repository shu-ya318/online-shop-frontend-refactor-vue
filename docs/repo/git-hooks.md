# Git hooks(husky、lint-staged)

在 Git Commit 前檢查指定項目，確保程式碼品質。

## 接入時機

### 設定語法對應效果

| 做法                           | 效果                                 |
| ------------------------------ | ------------------------------------ |
| 最後才接                       | 前面每個 commit 才不會被擋           |
| 驗收:故意改壞一個檔案後 commit | 確認 commit 會被擋住,代表 hooks 生效 |
