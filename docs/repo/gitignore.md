# .gitignore

排除建置產物。

## 排除清單

### 設定語法對應效果

| 排除項目               | 效果                         |
| ---------------------- | ---------------------------- |
| `node_modules`、`dist` | 建置與安裝產物不納入版本控制 |
| `.env.local`           | 本機環境變數不納入版本控制   |
| 測試報告               | 測試產物不納入版本控制       |

### 應避免的錯誤

- 建置產物沒排除,`git status` 出現多餘的檔案(驗收標準:`git status` 沒有多餘的建置產物)。
