# .gitattributes

一個區域:換行字元。

## 換行字元

### 設定語法對應效果

| 設定          | 效果                                                     |
| ------------- | -------------------------------------------------------- |
| `* text=auto` | Git 自動判斷文字檔並正規化換行                           |
| `eol=lf`      | 文字檔在工作目錄一律使用 LF,Windows 與其他系統的換行一致 |

### 應避免的錯誤

- 移除此設定,不同作業系統的換行(CRLF / LF)不同,可能造成整檔 diff 或 `.editorconfig`、Prettier 的換行設定被覆蓋。
