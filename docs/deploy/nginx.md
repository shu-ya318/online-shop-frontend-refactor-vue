# nginx.conf

分為「SPA fallback」與「反向代理」兩個區域。

## SPA fallback

### 設定語法對應效果

| 設定                         | 效果                   |
| ---------------------------- | ---------------------- |
| `try_files $uri /index.html` | 重新整理子路由不會 404 |

### 應避免的錯誤

- 沒設 fallback:重新整理子路由會 404。

## 反向代理

### 設定語法對應效果

| 設定                            | 效果                                            |
| ------------------------------- | ----------------------------------------------- |
| `/api/v1`、`/ws` 反向代理到後端 | 與 vite dev proxy 的路徑一致,開發與部署行為相同 |

### 應避免的錯誤

- 路徑與 vite.config 的 dev proxy 不一致。
